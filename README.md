## Features

### 1. Contact Form Validation

The website validates:

- Name field
- Email field
- Message field

Invalid or empty inputs are rejected.

When valid information is entered, a local preview is displayed on the page.

No data is sent to a server.

---

### 2. Theme Switch

Users can switch between light mode and dark mode to improve readability and user experience.

---

### 3. Study Hours Calculator

Users can enter:

- Hours per day
- Days per week
